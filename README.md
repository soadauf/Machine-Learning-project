# Machine-Learning-project
Training several machine learning models on hotel dataset and feature engineering to guarantee optimal results.
This project was done on hotel cancellation dataset on kaggle, to run the project the file machine learning project.ipynb has all the code required.
By the end the model will be able to predict the cancellation percentage according to the features designed which minimises the risk of losing the reservation last minute.
